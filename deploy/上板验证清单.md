## 3. 调禁区（10 分钟）—— 今天最该做的事

当前 `config.json` 的 `zone` 是占位矩形：

```json
[[0.25, 0.2], [0.75, 0.2], [0.75, 0.8], [0.25, 0.8]]
```

含义：画面横向 25%~75%、纵向 20%~80% 的矩形区域。

调试方法：**看板上没有画面，所以用检测窗口对照** —— 检测窗口显示的画面就是 640×480 坐标系，你说的「画面中间那块」对应的归一化坐标就是 zone。

```bash
nano /home/dwb/cangyan/config.json     # 改 zone
# 改完重启
sudo systemctl restart cangyan  # 或用 run.sh 手工重启
```

- [ ] 手伸进「要让评委看到报警」的那块区域 → 看板红条亮起
- [ ] 手退到区域外 → 约 1 秒内红条消失
- [ ] 如果手在外面也报警 → zone 太大，缩小；如果伸进去不报警 → zone 太小或位置偏

**判定技巧**：人站在画面正中，框中心坐标约 (0.5, 0.5)。想让「桌面中间」报警，zone 就包住中心那一片。

## 失败速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 服务起不来 | `User=` 不是 `dwb` | `systemctl cat cangyan` 看 User 行；install.sh 会按当前用户改写 |
| 起来了但没窗口 | 自动登录没生效 | `cat /etc/gdm3/custom.conf` 看 `AutomaticLogin` |
| 窗口有、看板打不开 | 8080 被占 | `ss -ltnp \| grep 8080` |
| 一直告警不解除 | 旧版 monitor.py | 确认已换成打过看门狗的版本：`grep -n idle_watchdog monitor.py` |
| 检测没框 | 摄像头节点变了 | `v4l2-ctl --list-devices`，改 `camera` |
| 禁区判定偏 | `frame_w/h` 不是 640/480 | 改回来 |
